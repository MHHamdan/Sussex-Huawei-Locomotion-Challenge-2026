# Sussex-Huawei Locomotion Challenge 2026 — FeatureFlyers

Repository for developing the **FeatureFlyers** team pipeline for the
[Sussex-Huawei Locomotion Challenge 2026](http://www.shl-dataset.org/activity-recognition-challenge/).

---

## Challenge Summary

**Task:** Transportation and locomotion mode recognition from mobile-phone sensor data.

The challenge provides multi-position (Bag, Hand, Hips, Torso) inertial measurement unit (IMU)
recordings collected with the Sussex-Huawei Locomotion (SHL) dataset. Each sample is labelled
with one of eight locomotion modes:

| Label | Mode    |
|-------|---------|
| 1     | Still   |
| 2     | Walking |
| 3     | Run     |
| 4     | Bike    |
| 5     | Car     |
| 6     | Bus     |
| 7     | Train   |
| 8     | Metro   |

**Key constraint:** Foundation models must remain **frozen**. Only lightweight task-specific
components (classification heads, adapters) may be trained.

## Dataset

The dataset is **not committed to Git**. Large sensor files are kept locally only.

```

├── raw/

│   │   ├── Bag/       # Acc_x.txt, Acc_y.txt, Acc_z.txt, Gyr_*, Mag_*, Label.txt
│   │   ├── Hand/
│   │   ├── Hips/
│   │   └── Torso/

│   │   ├── Bag/

│   │   ├── Hips/
```

### Dataset scale

| Split      | Positions | Samples/position | Sensors |
|------------|-----------|-----------------|---------|
| Train      | 4         | ~98 M           | 9 (Acc×3, Gyr×3, Mag×3) |
| Validation | 4         | ~14.4 M         | 9       |
| Test       | 1 (flat)  | ~92 K           | 9       |

### Placing the data

Place the official `.zip` files inside `dataset/` (they are already excluded from Git), then run:

```bash
python scripts/prepare_dataset.py          # extract to dataset/raw/, move archives
python scripts/inspect_dataset.py          # verify structure and counts
python scripts/convert_to_hdf5.py          # convert to dataset/processed/shl2026.hdf5
```

## Methodology

All experiments follow a **frozen-foundation-model** paradigm:

1. **Classical ML baseline** — handcrafted statistical features (mean, std, FFT energy, …) + Random Forest / SVM.
2. **Deep time-series baseline** — 1-D CNN or LSTM classifier trained end-to-end on raw windows.
3. **Frozen foundation model + head** — extract embeddings from a frozen time-series foundation model (e.g. Moirai, TimesFM, MOMENT), train only a linear or MLP head.
4. **Feature extraction + ensemble** — combine multi-position embeddings with a lightweight ensemble.

See [`docs/modeling_plan.md`](docs/modeling_plan.md) for the full staged plan.

## Setup

### 1. Create a Python environment

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 2. Install the package in editable mode

```bash
pip install -e .
```

### 3. Prepare the dataset

```bash
python scripts/prepare_dataset.py          # extract zips → dataset/raw/
python scripts/inspect_dataset.py          # verify structure
python scripts/convert_to_hdf5.py          # convert → dataset/processed/shl2026.hdf5
```

### 4. Validate the HDF5 file

```bash
python scripts/validate_hdf5.py
```

### 5. Explore label distributions

```bash
python scripts/analyze_labels.py           # saves outputs/eda/label_analysis.txt
```

### 6. Train the baseline

```bash
# Fast mode — 5 000 windows, Bag position, Random Forest
python scripts/train_baseline.py --sample-limit 5000

# Single position, full training data
python scripts/train_baseline.py --positions Bag --model rf

# All 4 positions, full data (slow, ~1 h on CPU)
python scripts/train_baseline.py --positions Bag Hand Hips Torso --model rf
```

Results land in `outputs/baseline/<run-name>/metrics.json`.

## Dataset structure notes

- **Train / Validation**: stored flat as `(N, 9)` float32 in HDF5; windowed on the fly.
- **Test**: stored pre-windowed as `(92 726, 500, 9)` float32 — 92 726 windows × 500 samples × 9 sensors.
- **Submission format**: 92 726 lines × 500 comma-separated integer predictions per line = 46 363 000 per-sample labels.

## Reproducibility

- All experiments are driven by YAML configs in `configs/`.
- Scripts accept `--config` to override the default config.
- Random seeds are set via `seed` in the config (default 42).
- All outputs (logs, checkpoints, predictions) go under `outputs/` and are excluded from Git.

---

## Git / Large-file Policy

The following must **never** be committed:

- `dataset/` (raw, processed, archives)
- `outputs/`
- `checkpoints/`
- `*.hdf5`, `*.h5`, `*.pt`, `*.pth`, `*.ckpt`
- Python cache (`__pycache__/`, `*.pyc`)

Use external storage (NFS, object store, DVC) for large artifacts.
